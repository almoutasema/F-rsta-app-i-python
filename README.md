# Advanced Calculator 🧮
This is a **Python-based calculator app** designed for learning and practicing Python programming. It performs basic arithmetic operations and may include some advanced calculations. The project includes a main Python script and a screenshot of the application interface.

## Repository Files
- **One.py** – Main Python script containing the calculator logic  
- **App.png** – Screenshot of the calculator interface  
- **.idea/** – IDE configuration files (optional)  
- **README.md** – This file

## How to Run
1. Make sure **Python** is installed on your system  
2. Clone the repository: `git clone https://github.com/Mats914/First-app-i-python.git`  
3. Navigate to the project folder: `cd First-app-i-python`  
4. Run the calculator: `python One.py`

## Features
- Basic arithmetic: addition, subtraction, multiplication, division  
- Advanced operations (if implemented in the script)  
- Simple and easy-to-use interface

## Notes
- Designed for beginners to practice Python programming  
- No external dependencies required unless specified in the code  
- You can modify the code to add more functionality or customize the interface
